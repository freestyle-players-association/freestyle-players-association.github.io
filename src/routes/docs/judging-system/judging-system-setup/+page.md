# Judging System Setup

Step-by-step guides for setting up and running an event with the Fpa2027 judging system are in the [freestylejudge.com Wiki](https://freestylejudge.com/wiki). The Wiki needs no sign-in.

- [Running an event as head judge](https://freestylejudge.com/wiki/head-judge): from getting access to sharing the results. Set up the event, run each routine, set up the judges.
- [Running the system locally](https://freestylejudge.com/wiki/local-server): for venues with weak internet. Run the app on a laptop with its own database, with the judges' phones on a hotspot, synced to the main site.

For how the judging and scoring work, see [Fpa2027 Judging](/docs/judging-system/fpa2027-judging).
